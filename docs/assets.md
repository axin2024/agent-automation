# 发行文件与素材权利

| 发行内容 | 来源和许可 |
| --- | --- |
| PHP、JavaScript、迁移、构建配置与文档 | 本项目源码，Apache-2.0 |
| `public/sample.json` 和测试夹具 | 合成邮箱、虚构订单和自包含测试响应，随项目以 Apache-2.0 发行 |
| `docs/results` | 本项目用合成数据和隔离工作区运行得到的记录，随项目以 Apache-2.0 发行 |
| PHP、MySQL、容器镜像和模型服务 | 部署者按各上游条款安装。源码发行包不包含运行时二进制和模型权重 |
| 字体和媒体 | 工作台使用系统字体。发行包未包含字体、图片或影音素材 |

Qwen2.5 权重和 llama.cpp 仅用于独立复测。上游来源与测试版本见 [验收记录](validation.md)。项目发行信息见 [LICENSE](../LICENSE) 与 [NOTICE](../NOTICE)。

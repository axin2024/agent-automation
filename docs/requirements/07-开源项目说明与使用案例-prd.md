# 可视化 AI 业务自动化平台｜开源项目说明与首个案例

**agent-automation** 是面向自托管的 PHP 项目。面向业务流程的连接器和审核工作台，支持确定性节点和真实模型节点，发布门槛以可复跑流程为准。 本页作为后续公开使用手册的需求稿，实际发行时补入测试版本、安装入口与已验证的依赖组合。

## 准备

邮件夹具、样例订单、模型连接器、工单服务与本地收件箱。

模拟售后邮件重复投递，订单查询返回一笔已发货订单；模型拟回复后修改订单状态，审批人核对并确认最新版本。

## 第一次使用

1. 从示例模板绑定本地订单、工单与收件箱，发布 V1，输入一封售后邮件。
2. 重复提交同一邮件号，在运行详情检查一个工单和一个待审回复。
3. 修改源订单状态，尝试批准旧正文，核对版本失效后重新取数并批准新稿。
4. 让发送端接收后断开回执，在查单确认前检查没有新增发信，最终核对收件箱只有一封。

## 对照综合样例

只建一个工单，过期草稿需刷新，最终外发一次；发送结果未知进入查单且不自动重发。 对照结果时保留源记录号、版本和操作时间，追踪从输入到最终交付的关联。

## 制造一次可恢复的异常

修改收件人后旧批准不生效。回到对象详情核对 approval 和审计记录，再按指定版本恢复或重试。确认相同操作不会生成两份有效结果。

## 自托管与反馈

处理外部文档和模型返回值时只按已配置字段映射，不能据输入内容获得额外工具权限。 提交问题请提供版本、最小合成输入、预期与实际结果。对接扩展可从以下方向开始：节点、连接器、工作流模板；贡献需附正常、失败、结果未知三种回放。

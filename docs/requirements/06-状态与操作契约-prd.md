# 可视化 AI 业务自动化平台｜状态与操作契约

## 流程实例的生命周期

待触发→运行→待人审或待外部回执→完成、失败或取消。恢复以已持久的节点输出为起点。

## 权限与操作者

流程作者设计草案，业务审批人确认外发内容，运营人员处理失败运行，管理员配置租户连接。 在待审批与已完成状态分别检查读写范围，委托与代办保留真实操作者身份。

## 两个关键交互

1. 作者发布图版本与节点契约，返回摘要、缺失凭据和不可达分支；运行冻结当时版本。
2. 审批绑定内容摘要和收件端，编辑输出或订单状态失效须重新审查，发送前复核授权。

## 业务操作与异常回执

| 操作域 | 在当前数据上的处理 | 冲突、拒绝或降级行为 |
|---|---|---|
| 工作流设计 | 保存类型化端口、必填字段和错误分支，支持试算样本；发布前诊断引用、不可达节点和非法环。 | 模型字段缺失时进入已定义异常分支。 |
| 连接与凭据 | 凭据按租户、环境与用途授权，编辑者只看引用，轮换后测试最小操作。 | 测试身份无法调用正式发送连接。 |
| 触发与任务 | 输入身份绑定流程版本，分配运行前核对并发与预算；重复输入返回同一运行。 | 超额度显示排队或拒绝原因。 |
| 模型与工具 | 声明模型能见字段、允许工具和返回结构，缺证时转人审，提取值不得自行扩大动作范围。 | 正文声称已获发信许可时仍需通过审批。 |
| 审批与外发 | 审批固定收件人、正文和业务数据版本，任一关键字段变化即需复审，外部发送有稳定业务键。 | 修改收件人后旧批准不生效。 |
| 运行与恢复 | 结果分业务拒绝、暂时故障和结果未知；重跑只处理安全节点，对外副作用先查单。 | 发送端成功但响应丢失，查单前不重新发送。 |
| 模板与发布 | 模板嵌入字段契约和夹具，导入需重新绑定本地凭据，活动版本切换不修改在途运行。 | 模板导出中不存在密钥值。 |
| 运营与评测 | 区分人工等待、推理耗时及第三方服务时间。对分类、字段提取、需转人工的结果分别抽检。 | 合成提示污染样例不能触发额外工具。 |

## 失联、中断及恢复

触发键、流程版本、节点与外部操作号持久化。审批仅放行其冻结内容，外部通知经事务待发与回执核对。 中断后先查询最后一个已持久的业务标记，再决定安全重试、补偿或人工复核。对外回执携带对象身份及业务版本。批量操作允许逐项查看成功、失败和未开始。

## 发布级业务断言

处理外部文档和模型返回值时只按已配置字段映射，不能据输入内容获得额外工具权限。 只建一个工单，过期草稿需刷新，最终外发一次；发送结果未知进入查单且不自动重发。

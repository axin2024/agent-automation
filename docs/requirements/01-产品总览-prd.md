# 可视化 AI 业务自动化平台｜产品总览

**正式需求基线 v2 · PHP · 独立开源项目**

面向业务流程的连接器和审核工作台，支持确定性节点和真实模型节点，发布门槛以可复跑流程为准。

## 使用者与责任边界

流程作者设计草案，业务审批人确认外发内容，运营人员处理失败运行，管理员配置租户连接。

## 完整交付链路

工作流设计 → 连接与凭据 → 触发与任务 → 模型与工具 → 审批与外发 → 运行与恢复 → 模板与发布 → 运营与评测。

## 产品范围与里程碑

| 里程碑 | 能力 | 交付物或判断依据 |
|---|---|---|
| 基础数据与首笔业务 | 工作流设计、连接与凭据 | 沙箱连接可在试运行读取虚构订单。 |
| 贯通核心生产流程 | 触发与任务、模型与工具、审批与外发 | 批准后的原稿一次送达本地收件箱。 |
| 异常、运营与独立交付 | 运行与恢复、模板与发布、运营与评测 | 错误订单号被人工纠正后可回看原始路径。 |

里程碑用于排开发顺序。首个完整公开版包含本项目全部 8 个业务域、24 项细分能力以及验收表的全部编号场景。

## 公开演示与成效

模拟售后邮件重复投递，订单查询返回一笔已发货订单；模型拟回复后修改订单状态，审批人核对并确认最新版本。

只建一个工单，过期草稿需刷新，最终外发一次；发送结果未知进入查单且不自动重发。

1000 封样例含 100 次重复投递，唯一工单数与唯一邮件身份数一致，未经审批外发为零。以上为发布目标，验收报告须给出实测环境及原始记录。

## 边界与外部依据

处理外部文档和模型返回值时只按已配置字段映射，不能据输入内容获得额外工具权限。

接口和业务术语的参考材料见 [n8n 文档](https://docs.n8n.io/)。具体范围由本项目的操作契约与验收用例界定。

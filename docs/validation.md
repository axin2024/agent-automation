# 首版验证

| 已执行的场景 | 结果 |
| --- | --- |
| PHP 8.2.30、MySQL 8.4.13 | 空库安装版本 1 后升级到 2，旧环境凭据可读 |
| 售后邮件及重复输入 | 相同身份和内容重放相同运行，改内容返回 409，其他租户查不到运行 |
| 审批修订和投递 | 三个草稿修订，旧订单状态或旧收件人使原批准失效，以新修订批准后只尝试一次投递 |
| 发送端提交成功后丢回执 | 收件端保存一条回执，来源状态变为 `unknown`，重复查单读回同一回执 |
| 人工纠正及回滚 | 保留错误订单和更正后的号码；已触发运行在冻结版本继续，新运行按回滚后的图执行 |
| 报错和额度 | 循环和审批旁路图被拒，测试录制缺结果进入错误分支，超出未完结运行额度返回 429 |
| 独立 HTTP 部署与恢复 | 两个 PHP 进程分别处理 HTTP 与工作队列。客户端用公开接口完成一份样例，SQL 备份导入第二个库，回读同一工单和投递回执，尝试次数为 1 |

生命周期用例的业务部分用时 1.424 秒。规则路径和录制出错路径均实际执行。独立部署与恢复用例可用 `scripts/test-mysql.ps1 -Scenario Deployment` 重跑。
